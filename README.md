# MINGO 작업대

MINGO의 공개 문서 허브입니다. 앱·API·관리자 기능을 제공하거나 블록체인 기능의 배포 완료를 나타내는 사이트가 아닙니다.

## 문서

- [작업대](index.html): 문서 목록과 공개 원칙
- [모바일 설치 안내](mobile.html): 기존 Android APK 링크와 설치 안내 보존
- [ART PASS 블록체인 보고서](reports/blockchain.html): 기술선정 제안 / 구현 전 검토
- [보고서 Markdown 원문](reports/mingo-art-pass-blockchain.md): 편집 기준이 되는 전문

보고서는 **2026-11-10 조사 기준**, **2026-11-14 문서 정리**입니다. 권고는 구현·배포·감사·실제 비용 측정의 완료를 뜻하지 않습니다.

## 편집과 로컬 확인

Python 3.9 이상과 표준 라이브러리만 사용합니다. npm 설치나 빌드 서비스는 필요하지 않습니다. 배포된 페이지는 HTML/CSS만으로 동작합니다.

```sh
python3 tools/render_report.py
python3 tests/check_site.py
python3 -m http.server 8000 --bind 127.0.0.1
```

로컬 브라우저에서 포트 8000의 루트 페이지를 열어 확인합니다. 375px·768px·1440px 너비, 키보드 포커스, 긴 출처 URL의 줄바꿈을 점검합니다. 자동 검사는 내부 링크·앵커·자산과 문서 전문·생성 결과의 일치를 검사하며, 외부 사이트나 APK의 가용성 및 브라우저 화면 품질은 보증하지 않습니다.

보고서 수정은 `reports/mingo-art-pass-blockchain.md`에서 진행하고 렌더러를 다시 실행합니다. 생성된 `reports/blockchain.html`을 직접 수정하지 마세요. 렌더러는 제목·문단·평면 목록·인용·구분선·강조·코드·HTTP(S) 원문 URL을 지원하고 raw HTML은 이스케이프합니다. 표·중첩 목록·Markdown 링크 등은 지원하지 않습니다. 해당 문법이 필요하면 렌더러와 테스트를 함께 확장하세요.

새 문서는 상대경로 링크로 추가하고, `index.html`의 실제 문서 목록에 목적·상태·기준일을 적습니다. 빈 메뉴나 예정 문서 카드는 추가하지 않습니다. 디자인 기준은 [DESIGN.md](DESIGN.md)를 따릅니다. 모바일 안내는 앱 업데이트 작업과 분리하며 APK 링크 변경은 별도 확인이 필요합니다.

## 발행

저장소 이름과 Pages 주소 경로 `mingo-mobile-guide`는 유지합니다. 현재 발행 소스는 **main 브랜치 / 루트**입니다. 검토 후 담당자가 원문·생성 HTML·관련 자산을 함께 커밋하고 main에 반영하면 GitHub Pages가 발행합니다. 반영 후 Pages 작업의 성공 여부와 실제 발행 페이지·내부 링크를 다시 확인합니다. 로컬 테스트 성공만으로 공개 사이트 반영을 주장하지 않습니다.
